# Infinity 2.0.3 Preview — Critical performance fix

Recommended for everyone using Infinity 2 Preview.

- Fixed sluggish and stuttering page scrolling, including rapid wheel input and direction changes, while retaining animated page centring.
- Reduced overview opening and scrolling delays by preloading the shared wallpaper and avoiding unnecessary page refreshes.

Signed installers are available for Windows x64 and ARM64. Existing Infinity 2 installations can update through the app.
